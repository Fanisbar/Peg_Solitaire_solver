This game is formally known as *peg solitaire*  
more info: https://en.wikipedia.org/wiki/Peg_solitaire

To play the game, visit:  https://fanisbar.github.io/Peg_Solitaire_solver/  
To use the AI solver, run `python main.py` (or `python3 main.py`) on the root of this repository  
If you are using WSL and running this command doesn't work, try running `export DISPLAY=:0` first and then the command above.
